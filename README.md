# 从本体建模到知识工程

这是一套面向开发者和业务建模人员的中文教程。我们从一个媒体资料库开始，逐步学习如何定义领域概念、表达事实，并追溯每条事实所依据的材料。入门练习只需要会运行 Python 3，无需图数据库或在线服务。

## 从这里开始

1. 阅读[入门课：一个人可以有几个角色？](docs/01-从问题到模型.md)。
2. 在仓库根目录运行 `python3 examples/media/roles.py`，查询同一人在两部作品中的角色。
3. 对照[教学大纲与阅读清单](tutorial-planning/本体驱动的知识工程开源教程-教学大纲与资料清单.md)，了解后续章节。

## 学习路线

| 阶段 | 需要回答的问题 | 对应章节 |
| --- | --- | --- |
| 确定范围与建模 | 系统应回答哪些问题？作品、版本、文件和参与角色如何区分？ | 1–4 |
| 表达与验证 | 怎样用 RDF 表达事实、用 SPARQL 查询、用 SKOS 管理术语、用 OWL 推理、用 SHACL 校验？ | 5–8 |
| 证据与应用 | 怎样审核抽取结果、处理冲突、管理版本，并评价知识应用？ | 9–12 |

目前可学习的是入门课和配套实验，十二章完整课程仍在编写规划中。案例的设计背景见[媒体文化企业本体知识系统草案](媒体文化企业本体知识系统-建设与抽取流程说明.md)。
