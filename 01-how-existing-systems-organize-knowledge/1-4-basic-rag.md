# 1.4 基础 RAG 的检索实验：召回与重排

## 本节大纲

你问“四点二十到还来得及借书吗？”检索系统能从上一节的五个片段里找到办证条款 D-1 和借阅公告 C-1 吗？

1. **建索引。** 给同一批片段建立关键词索引和向量索引，保留片段编号，方便把每次查询的结果对应到原文。
2. **比较召回。** 用同一提问分别做关键词、向量和混合检索，记录各自找回了哪些片段，看看 D-1 和 C-1 是否都在候选里。
3. **观察重排。** 对同一组候选按问题重新排序，比较排序前后实际送给模型的片段。如果 C-1 在召回时就已遗漏，重排能改变什么？
