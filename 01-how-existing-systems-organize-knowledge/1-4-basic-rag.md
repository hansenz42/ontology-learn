# 1.4 基础 RAG 的检索实验：召回与重排

## 本节大纲

你问“四点二十到还来得及借书吗？”检索系统能从上一节的四份文档里找到办证指南 D 和借阅公告 C 吗？

1. **建索引。** 给这四份文档建立关键词索引和向量索引，保留文档编号，方便把每次查询的结果对应到原文。
2. **比较召回。** 用同一提问分别做关键词、向量和混合检索，记录各自找回了哪些文档，看看 D 和 C 是否都在候选里。
3. **观察重排。** 对同一组候选按问题重新排序，比较排序前后实际送给模型的文档。如果 C 在召回时就已遗漏，重排能改变什么？
