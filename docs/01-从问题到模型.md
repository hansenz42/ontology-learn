# 入门课 · 一个人可以有几个角色？

[导论](00-企业RAG与本体.md)里，编辑已经核对了两部作品的发行版片尾。现在把审核通过的署名录入资料库。编辑想查“林青在哪部作品中担任导演？”先写下两条虚构的片尾署名，用来检验建模结果。

| 作品 | 姓名 | 署名角色 |
| --- | --- | --- |
| 河流来信 | 林青 | 导演 |
| 城市回声 | 林青 | 嘉宾 |

两条署名中的林青是同一个人。我们希望查“林青参与了哪些作品”时得到两条结果，查“林青导演了哪些作品”时只得到《河流来信》。这种用来界定模型需要回答什么的问题叫作**能力问题**。

## 作出建模选择

如果给人物记录加一个“导演”标签，再列出她参与的所有作品，那么筛出“有导演标签的人参与的作品”会多返回《城市回声》。丢失的信息是角色与具体作品之间的对应关系。

为此，示例给人物和作品各自分配标识符，再用一条**参与记录**连接人物、作品和角色。林青在两条记录里使用相同的人物标识符。即使另一位作者也叫林青，给新作者分配独立标识符，就可以分别查询。

## 动手验证

在仓库根目录运行以下命令。

```sh
python3 examples/media/roles.py
python3 examples/media/roles.py 导演
```

第一次应看到两条署名。第二次只应看到“林青｜河流来信｜导演”。试着把[实验数据](../examples/media/participations.csv)里《城市回声》的角色改为“导演”，预测第二次查询的结果，然后重新运行。两部作品现在都满足条件。

这个实验用表格表达一个最小模型。它能检查查询是否区分角色，但无法证明片尾署名本身正确。若要回答“谁能证明这条署名”，参与记录还需要关联具体来源，例如某个发行版本的片尾时间码。
