# 2.1 清单漏了一部，问题在哪一步？
把问题的范围固定为练习中的两部作品和它们的发行版，查询人可以看到 A、B、C。人工先读两份片尾，写下导演清单的预期集合：《河流来信》。这个小集合可以穷举，所以能明确判断漏项。

## 重放一个空答案
假设基线返回“未查到”。先检查原件清单。A 在共享目录里，再检查解析产物，发现片尾字幕从 24:00 处被截断，24:10 的署名没有进入索引。此时把检索条数从三条改成十条也得不到 A。重新解析完整片尾，检查片段是否可按作品标识找回，再重跑查询。这是对一种故障的模拟，不代表某个线上系统的测量结果。

换一个条件：索引中已经有 A，关键词搜“林青”也能找到，但回答此次问题时返回的候选列表只有 B。接下来应该查看查询过滤条件、排序和返回条数。若 A 在候选列表中，却没有进入最终上下文，还应检查重排和截断。

## 把诊断写成记录
为每次试验保留预期集合、实际集合、缺失项和第一个出现差异的位置。对这个一项的集合，实际返回空集意味着唯一的正确项漏掉了。尚未完成资料普查的大馆藏，通常没有这样的完整参考集合；要说明评估覆盖哪些作品和日期。

## 思考
假如询问者只能看提案，不能看片尾，同样的空答案是否还是漏项？先按可见材料重写这一用户的预期，再判断。

**自查。** 参考判断：先在可见范围内确定参考答案。当前身份能回答什么，与完整馆藏实际有什么，是两项不同的检查；不要通过答复泄露受限作品的存在。

## Q&A
**补录后答对一次，能关闭这个问题吗？** 把原问题连同固定快照保留为回归样例；再用另一种说法重问，分别观察补录和查询改写的影响。
