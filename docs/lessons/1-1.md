# 1.1 同一条署名，为什么既要文件也要表？
编辑接到一个看似简单的任务：把《河流来信》的导演名字填进片单。打开成片，拖到 24:10，片尾写着“导演：林青”。填好名字只花几秒。一个月后有人问“你当时看的是哪个版本”，只剩姓名的片单已经无法回答。

## 从一次交接开始
本教程使用三份虚构原件。把下面的表抄在纸上，先遮住最后一列，请同事只凭资料名猜它能证明什么，再打开原句核对。

| 编号 | 原件与位置 | 记录 |
|---|---|---|
| A | 《河流来信》发行版片尾 24:10 | 导演：林青 |
| B | 《城市回声》立项提案第 2 页 | 拟邀林青执导 |
| C | 《城市回声》发行版片尾 46:20 | 导演：周明；访谈嘉宾：林青 |

文件目录帮助人找到一份材料。业务表适合回答“哪几行满足条件”。表的每一行必须先说清代表什么：若一行代表一部作品，《城市回声》有两个人、两个角色；若一行代表一条片尾署名，C 就会产生两行。这项选择叫作记录的粒度，它决定以后筛选时能保留哪些区别。

## 做一张可以交接的表
给 C 的两条署名分别填入人物、角色、发行版本、来源编号和位置。两行共享 C 和 46:20，各自保存一个人和一个角色。给这两行不同的行标识，之后改错一个姓名就能指出改的是哪一条。文件路径则作为查阅原件的入口；搬动文件时可以更新路径。

现在试着把 B 填进同一张表。它确实提到林青和执导，但你找不到它对应的发行署名。把它登记在提案记录里，保留“拟邀”，下次问“谁曾被邀请”时仍然用得上。

## 思考
同一发行版从一个视频文件转码出两个文件，应当给每条片尾署名再抄一遍吗？画出作品、文件、署名三列，观察抄录会怎样影响“有几位导演”的统计。

**自查。** 参考判断：转码给文件增加一个实例。先问版本和片尾是否变化；如果均未变化，沿原版本查同一条署名即可。验收表格时把 C 展开，角色必须仍与各自的人物配对。

## Q&A
**片名能当主键吗？** 在这两部片子的例子里碰巧够用。若发行版改名或两部作品同名，按片名连接就可能串行。给作品稳定标识，另外记录各版本使用的名称。
