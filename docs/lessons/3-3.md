# 3.3 用最小模型重答导演清单
现在把已有资料摊开，先不用数据库。目标是让另一个人照你的记录也能得到同样的作品集合和引用，并能解释为什么没有收录《城市回声》。

## 四张卡片
从两份发行片尾得到三张署名卡：林青—导演—《河流来信》发行版—A 24:10；周明—导演—《城市回声》发行版—C 46:20；林青—访谈嘉宾—《城市回声》发行版—C 46:20。再为提案制作一张拟邀卡：林青—拟邀执导—《城市回声》—B 第 2 页。它支持的是一项计划。

## 手算一次图查询
先取人物为林青的卡片，剩三张；再取发行署名，剩两张；要求角色为导演，剩 A 的一张。从发行版本回到所属作品，写下《河流来信》和 A 的位置。这条路径能原样交给后续课程的查询实现。

现在有意去掉角色条件。结果应增加《城市回声》，依据是 C 的嘉宾记录。如果它仍未出现，检查嘉宾署名是否漏录。改问“哪个项目曾拟邀林青执导”，从拟邀卡筛选，应得到《城市回声》和 B。这三个检查比盯着一次正确答案更容易发现记录结构中的错误。

## 思考
假设 A 丢失，沿刚才的步骤会得到什么？区分“当前未找到有证据的署名”和“她从未执导过作品”。把这个未知项保留到第二章的失败表。

**自查。** 参考判断：没有 A，发行署名筛选后没有命中。应记录“已检查材料中没有找到该署名”，保留补齐片尾后再查的入口；不能由此推断林青的职业经历。

## Q&A
**可以动手运行这个例子吗？** 在仓库根目录运行 `python3 examples/media/roles.py 导演`。这个入门实验覆盖两条林青署名及角色筛选，四张卡片里的拟邀、来源和版本在本节用纸笔核对。
