# 1.3 一次查询究竟读了哪些材料？
员工问“林青执导过哪些已发行作品？”这是在要一份清单。若只记录模型最后说了什么，就很难判断是材料没找到，还是找到了却读错。给这次查询留一张记录卡，保留请求身份、原问题、返回片段、交给模型的上下文、答案和引用。

## 沿查询走一遍
假设检索返回 B、C、A。这是手工设定的教学顺序。B 与“林青”“执导”字面接近，可能排得靠前。若只把第一段送进模型，后面两份发行片尾无法参与回答。若把三段都送入模型，则应当逐项检查：A 支持林青在《河流来信》任导演；B 支持一次拟邀；C 支持她在《城市回声》任嘉宾。

检索系统可以用文档类型和权限过滤，用重排模型重新排列候选。把提问改成“谁曾被拟邀”时，发行版过滤反而会删掉需要的 B。因此，过滤条件也属于本次查询的记录，不能藏在一句“使用了知识库”后面。

## 验证一次引用
在纸上列两栏：左边写答案中的每项主张，右边写能支持它的原句。试给“林青执导《城市回声》”填右栏。B 有“执导”但有“拟邀”；C 有姓名但角色是嘉宾。两条引用叠在一起也填不出一条正式导演署名。

## 思考
同样得到错误答案，记录显示“只返回 B”和“返回 A、B、C”时，你分别会先检查哪一步？

**自查。** 参考判断：第一种检查检索与截断；第二种逐项核对角色、材料状态和答案中的引用。请给 C 上的两个名字分别标角色，避免一次阅读把它们交叉配对。

## Q&A
**找到一条正确记录就能说清单完整吗？** 得先约定资料范围。对本练习的两部作品可以穷举检查；对尚未编完的馆藏，答案应说明覆盖范围。
