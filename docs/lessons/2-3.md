# 2.3 这份资料有资格证明哪件事？
“哪个文档最权威？”把问题再具体一点：对于哪项事实、哪个版本、哪个时间点，哪位维护者认可这份资料？回答变具体以后，提案和片尾各有用途。

## 为来源写一张责任卡
给 B 写“可证明提案曾记载拟邀；范围是此版提案；位置为第 2 页”。给 C 写“可证明该发行版片尾如何署名；位置为 46:20”。若要研究实际劳动分工，片尾署名与实际做过哪些工作又是两个问题，需要另找依据。本教程的导演清单明确以发行署名为准。

假设现在收到一封邮件，称另一版片尾给林青的角色不同。第一步是确认邮件说的是同一发行版还是另一版。不同版本可以同时有不同署名；同一版本的两种说法才需要裁决。保存两种主张的来源，把缺失的版本标识列为待核项。直接按最新邮件覆盖旧行，以后就很难解释原报表。

## 试着作一个决定
读者可以画三栏：“主张”“足以支持它的材料”“当前状态”。把“林青曾被拟邀”填成已支持，把“她在 C 中署名导演”填成与片尾不符，把“她在未收录的另一个版本里担任什么”填成待核。三种状态要求三种不同措辞。

## 思考
两份内部汇总表都抄自同一封邮件，它们能算两份独立证明吗？试着追溯每份表最初引用的位置。

**自查。** 参考判断：沿两张表向上追，若最后都落到同一封邮件，应把它们看作同一来源的两次转述。即使文字一致，也不能代替片尾版本核验。

## Q&A
**能看到文件就能批准它成为正式结论吗？** 查看权限和审核职责是两个字段。员工能读到记录，采用决定仍需按团队约定交给有相应职责的人。
