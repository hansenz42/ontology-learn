# 1.4 LLM Wiki 把哪些知识留到了下一次？
读完一份材料后，编辑常会更新人物页。LLM Wiki 把这项整理工作交给模型辅助完成：持续维护相互链接的页面，下次查询时可以先读已经整理好的内容。页面怎么分、怎样保留来源，由项目约定。

## 亲手维护一页
给林青建一页，分成“发行署名”和“立项记录”两栏。先只读 B，在立项栏写“《城市回声》提案拟邀林青执导，见 B 第 2 页”。再读 C，在发行栏写“访谈嘉宾，见 C 46:20”。读 A 后补上《河流来信》的导演署名。更新人物页索引，使“林青”能定位到这页。

现在试问两个问题：“哪部片子曾邀请她执导？”沿立项记录回到 B；“哪部发行片署名导演？”沿发行栏回到 A。同一页把散落材料串起来，也保留了每项结论的证据。项目可以继续把页面交给全文或向量检索，供问答系统使用。

## 检查一次错误更新
设首次写页时把 B 简写成“林青导演了《城市回声》”。下一次助手读人物页，又把这句话写进作品页，两页相互链接。链接数量增加了，独立证据仍然只有 B。维护者需要找出哪些页面引用了错误摘要，重新读 B 和 C，修正两个页面并登记变化。

## 思考
如果 C 被更正，你会重读哪些页？先按来源反查，再说明为何只重写最近更新的页面可能留下一份旧答案。

**自查。** 参考判断：先找到人物页上引用 C 的陈述，再找到由该陈述生成的作品页或摘要。撤回一条支持时，应继续检查还有没有其他独立来源。

## Q&A
**人物页可以直接当权威来源吗？** 可以把经授权审核的页面设为特定事项的正式记录，但要讲清负责人和更正流程。本例的人物页是派生摘要，读者仍可回到原件核对。
