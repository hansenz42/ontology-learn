# 3.1 怎么判断还是同一个对象？
资料员收到三个变化：林青改用艺名，《河流来信》生成了新的交付格式，导演又剪出一版不同片尾。要给它们分配标识，得先回答“我们在数哪一种东西”。这是本体论里的同一性问题在编目工作中的具体形式。

## 三次变化，三种判断
艺名变化时，存在证据表明两个名字属于同一个人，就保留人物标识并增加名称及适用信息。如果只有字符串相同，仍需核实身份。文件转码时，新的编码产物可以拥有独立文件标识；在本项目的编目约定下，内容与发行决定均未改变，则两个文件关联同一发行版。

重剪使片尾署名发生变化时，给新剪辑单独登记版本。编辑要回答哪个版本写了谁，就能准确选择相应记录。是否仍属于同一作品取决于机构的作品认定规则。课程在这个例子里假定它是同一作品的另一版本，并把这个假定写入定义卡。

## 给自己的定义找麻烦
写下一条规则：“同名文件是同一个文件。”现在把两个完全不同的视频都命名为 final.mp4，规则立即失效。再试“内容一致就算同一文件”：对去重存储它可能有用，对追踪两份独立交付则可能丢失记录。先说明目的，再决定需要辨认的是内容、文件还是交付事件。

## 思考
一段片尾抽出来另存为视频，它与整片是什么关系？试分别回答“它是不是同一文件”“它是否来自这个版本”“它是否代表整部作品”。

**自查。** 参考判断：单独导出的片段文件与整片文件可以有不同标识。它取材于一个版本并只承载其中一部分；如果给片段新文件标识，不必因此增加作品计数。

## Q&A
**给每个东西发一个 ID 就解决身份问题了吗？** 标识能稳定引用记录。决定何时沿用或新建标识，仍需要身份判据和证据。
